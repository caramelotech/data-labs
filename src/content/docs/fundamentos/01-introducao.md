## O que é este laboratório?

Este repositório é um espaço de aprendizado prático de dados da Caramelo Tech.

O foco é trabalhar com dados de forma aplicada: coleta, transformação, análise e visualização.

## Tecnologias abordadas

- **SQL** - consultas, agregações, joins e modelagem relacional
- **Python** - pandas, numpy, visualização com matplotlib/seaborn
- **Engenharia de dados** - pipelines, ETL, qualidade de dados
- **Estatística aplicada** - medidas descritivas, distribuições, correlações

## Como está organizado

| Diretório                    | Conteúdo                            |
| ---------------------------- | ----------------------------------- |
| `/src/content/docs`          | Anotações e conceitos               |
| `/examples`                  | Scripts e queries prontos           |
| `/examples/exercises.md`     | Exercícios para praticar            |
| `/examples/projects.md`      | Projetos para construir             |

## Por onde começar

1. Leia estas anotações em ordem
2. Explore os exemplos em `/examples`
3. Resolva os exercícios em `/examples/exercises.md`
4. Monte os projetos em `/examples/projects.md`

## Dica

Não apenas leia - execute as queries, carregue os datasets, modifique os scripts.
Aprendizado real acontece na prática.
