## O que pode ter acontecido?

- A URL foi digitada com um erro de sintaxe (como um `WHERE` que não bate com nenhuma linha)
- O conteúdo foi movido para outra tabela - isto é, outra seção do lab
- O link que você seguiu aponta para um registro que foi deletado ou renomeado
